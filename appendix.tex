\section{Flat-Field Generation and Analysis Configuration} \label{app:config}

For reproducibility we record here the exact inputs used to build the deep $i$-band combined
flat and to run the single-detector analysis.

The analysis notebooks read the combined flats directly from the Butler at the USDF with the
following configuration:
%
{\footnotesize
\begin{verbatim}
BUTLER_PATH = "/repo/main"
COLLECTIONS = "u/plazas/LSSTCam/calib/none/treerings/flatGen-i.20260319b"
BAND        = "i"
\end{verbatim}
}
%
The chromaticity analysis instead reads the five-band combined flats from the standard
\texttt{LSSTCam/calib} collection.

The combined $i$-band flat was produced from 290 individual PTC flat exposures (taken with the
3s\_v2 ``natural-frequency'' sequencer on 2025-12-28) using the LSST Science Pipelines
flat-generation pipeline, submitted through the Batch Processing Service (BPS) at the USDF.
The submission script is reproduced below; the \texttt{SELECTION\_FLAT\_i} exposure list is
abbreviated here (the full set of 290 exposure IDs is preserved with the analysis code).
%
{\footnotesize
\begin{verbatim}
# Generate a combined flat image from i-band PTC flats to study tree rings (2026-02-26)
# Run this at USDF.

# STEP 0: set up the LSST Science Pipelines stack
source /sdf/group/rubin/sw/w_latest/loadLSST.bash
setup lsst_sitcom

# STEP 1: work from the home directory
cd ${HOME}

# STEP 2: environment / data selection
export USER_CALIB_PREFIX="u/plazas/"
export INSTRUMENT=LSSTCam
export TICKET="none"
export REPO=main
export RAW_COLLECTION=LSSTCam/raw/all
# Curated calibration inputs:
#   LSSTCam/calib/DM-53722: defects, bias, dark, linearity, etc.
#   LSSTCam/calib/DM-52726: flat gradient reference
#   LSSTCam/calib/DM-51599: CBP crosstalk for 3s_v1
#   LSSTCam/calib/DM-51669: curated calibrations
#   LSSTCam/calib/photodiode: photodiode data
export CALIB_COLLECTIONS=LSSTCam/calib/DM-53722,LSSTCam/calib/DM-52726,\
LSSTCam/calib/DM-51599,LSSTCam/calib/DM-51669,LSSTCam/calib/photodiode
export TAG=treerings
export RERUN=20260319b   # bump to "c", "d", ... to rerun

# Flats: 290 i-band PTC flats, 3s_v2 ("natural frequency") sequencer.
# Detector 122 is excluded.
export SELECTION_FLAT_i="instrument='LSSTCam' and detector not in (122) and \
exposure in (2025122800010, 2025122800011, 2025122800012, 2025122800013,
             2025122800014, 2025122800015, 2025122800024, 2025122800025,
             ...   # 290 exposure IDs in total (full list with the analysis code)
             2025122801080, 2025122801081, 2025122801084, 2025122801085)"

# STEP 3: sanity-check the resolved BPS YAML
cat $CP_PIPE_DIR/bps/templates/bps_flat_i.yaml | envsubst

# STEP 4: submit
bps submit -i ${RAW_COLLECTION},${CALIB_COLLECTIONS} \
    $CP_PIPE_DIR/bps/templates/bps_flat_i.yaml
\end{verbatim}
}
%
The per-exposure Poisson noise averages down as $\sqrt{290}$ in the combine, which is what
brings the $\sim10^{-4}$ tree-ring modulation above the single-flat noise floor.

\section{Per-Detector Tree-Ring Profile Tables} \label{app:tables}

We provide tabulated radial tree-ring profiles for all detectors and bands. The tables are
available from the authors (see Appendix~\ref{app:data}) and include:

\begin{itemize}
\item Detector ID
\item Band
\item Fitted center $(x_0, y_0)$
\item Initial center from HyeYun's catalog $(x_{0,\rm init}, y_{0,\rm init})$
\item Radial coordinate $r$ (pixels)
\item Profile amplitude $w(r)$ (fractional units)
\item Uncertainty $\sigma_w(r)$
\item Mask fraction versus $r$
\item Quality flags
\end{itemize}

\section{Data Products} \label{app:data}

The machine-readable products behind every figure and table in this note are available from
the authors on request, as a single $\sim$50\,MB archive carrying its own per-product
provenance record. They are produced by the analysis notebooks in the companion
\texttt{tree-rings-lsstcam} repository, listed by product below. Tabulated files are
gzip-compressed ASCII with a self-describing \texttt{\#} header. The product groups are as
follows.

\begin{description}

\item[\textbf{Centers.}] Tree-ring center fits for all 183 usable detectors from
\texttt{fit\_all\_ccd\_centers.ipynb} on the deep $i$-band flat: all three fitted centers
(\texttt{fft}, \texttt{rms}, \texttt{esteves}) plus the catalog seed (\texttt{hyeyun}), the
per-detector recalibrated ring-wavelength band, cross-method agreement flags, the recommended
working center per detector (\texttt{center\_winner\_by\_ccd.csv}), the seed catalog itself,
and a provenance JSON carrying the per-detector mask census (defect pixels, MAD-clip fraction,
good fraction) and full fitter diagnostics.

\item[\textbf{Radial profiles ($i$ band).}] The 1-D radial profiles $w(r)$ from
\texttt{extract\_1d\_profiles.ipynb}, measured on the \emph{unfiltered} combined flat
($F/\mathrm{med}(F)-1$) in $2$-pixel annuli with a median estimator, a MAD-based standard
error of the median, and a 1-D Gaussian trend ($\sigma=80$\,px) removed along radius. One
profile per detector at that detector's recommended working center, plus \texttt{R02\_S02}
at all four centers for the center comparison of Section~\ref{sec:center_compare}. Summary and 1-D
quality-metric CSVs cover all four centers for every detector. These profiles are the
photometric flat-field templates.

\item[\textbf{Astrometric displacement ($i$ band).}] The predicted radial astrometric displacement $f(r)$,
obtained from the profiles above by the \citet{Plazas2014} integral with the $-1$ sign
convention and a cubic large-scale trend removal, in units of pixels.

\item[\textbf{Chromatic profiles.}] Per-band ring profiles $w_b(r)$ for $b \in \{g,r,i,z,y\}$ from
the standard five-band \texttt{LSSTCam/calib} combined flats (not the deep $i$-band stack),
extracted about a single physical ring center per detector, together with the fitted
amplitudes $A_b$ relative to $g$, their correlation coefficients, and cross-correlation lags.

\item[\textbf{On-sky validation.}] The amplitude fit comparing the flat-derived prediction for
\texttt{R02\_S02} against the DP2 on-sky Gaussian-process astrometric residual maps.

\end{description}

Two caveats travel with these products. First, the center degeneracy along the
detector-to-center line (Section~\ref{sec:center_compare}) propagates into every profile and
displacement curve, so the transverse center uncertainty, not the two-dimensional scatter, is
the meaningful quantity. Second, the chromatic amplitudes are limited by the depth of the
\texttt{LSSTCam/calib} flats rather than by the method, and the \texttt{ordering\_ok} flag is
false for a substantial fraction of detectors; those amplitudes should be read together with
their correlation coefficients.
